Custom Fonts Example - O'z shriftlaringiz bilan ishlash namunasi

📝 Eslatma: Bu sahifada FontManager moduli qanday ishlashini ko'rsatish uchun oddiy misol keltirilgan. Real loyihada o'z shrift fayllaringizni qo'shing.

1️⃣ FontManager Initialization

import { FontManager } from './FontManager.js'; // FontManager obyektini yaratish const fontManager = new FontManager(); // Shrift definitsiyalarini qo'shish fontManager.addFontDefinitions([ { family: 'MyCustomFont', src: "url('/fonts/custom-font.woff2') format('woff2')", weight: 'normal', style: 'normal', display: 'swap' } ]); // Shriftlarni yuklash await fontManager.loadFonts();
